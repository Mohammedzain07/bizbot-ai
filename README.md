# 🤖 BizBot AI

BizBot AI is an AI-powered business chatbot designed to automate customer interactions, answer user queries, and provide intelligent business assistance through a modern web interface.

## 🚀 Features

- AI-powered chatbot interface
- Real-time user interaction
- Responsive and modern UI
- Frontend built with React + Vite
- Backend API integration
- Easy deployment and scalability

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- JavaScript

### Backend
- Node.js
- Express.js

## 📁 Project Structure

```
project_final/
```

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Mohammedzain07/bizbot-ai.git
cd bizbot-ai
```

### Frontend Setup

```bash
cd project_final/bizbot-ui
npm install
npm run dev
```

### Backend Setup

```bash
cd project_final/backend
npm install
npm start
```

## 🌐 Usage

1. Start the backend server.
2. Start the frontend application.
3. Open the local development URL provided by Vite.
4. Interact with the BizBot AI chatbot.

## 🎯 Purpose

The goal of BizBot AI is to provide businesses with an intelligent virtual assistant capable of handling customer queries, improving engagement, and reducing manual support efforts.
